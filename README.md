# Kannada Language Toolkit

A Kannada language toolkit for Varnamala, spelling correction, grammar correction, caption generation, transliteration, and dictionary search.

## Core features

- ಕನ್ನಡ ವರ್ಣಮಾಲೆ — ಸ್ವರಗಳು, ವ್ಯಂಜನಗಳು ಮತ್ತು ಯೋಗವಾಹಗಳು
- Kannada spelling checker
- Common Kannada spelling mistakes and corrections
- Basic grammar correction
- Poster and announcement text correction
- Formal, casual, and promotional Kannada captions
- Kannada ↔ English transliteration foundation
- Searchable Kannada word dictionary
- API-ready modular architecture
