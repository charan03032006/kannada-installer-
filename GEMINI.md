# Gemini / AI Agent Guide

## Install

Node.js 18+ is required.

```bash
npm install
npm test
```

## Project

Kannada Language Toolkit: Varnamala, spelling, grammar, captions, transliteration, dictionary, and poster correction.

Before changes, inspect `README.md` and `AGENTS.md`. Preserve Kannada UTF-8 data and run the test suite after modifications.
