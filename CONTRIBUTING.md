# Contributing

Contributions are welcome, especially new Kannada words, spelling corrections, grammar rules, examples, and tests.

## Guidelines

1. Keep Kannada data accurate and reviewable.
2. Add or update tests when changing behavior.
3. Keep modules small and reusable.
4. Avoid putting application-specific UI code in the language core.
5. Use clear commit messages.

For language-data contributions, include a short example showing why the entry is useful.
